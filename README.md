### hey

I'm Fei. I spend an unreasonable amount of time poking at browser-based tools — mostly the ones that promise to pull a video off some social platform and hand it back to you.

Half of them don't work. The other half work fine until the platform changes something, then quietly die. So I keep a short list of the ones that were still doing their job when I last checked.

**Media downloaders that still work (checked October 2026)**

- [clipdocky.com](https://clipdocky.com) — TikTok, watermark-free, keeps the audio track
- [reelvideosave.com](https://reelvideosave.com) — Instagram Reels; handles carousels without choking
- [tweetvideosave.com](https://tweetvideosave.com) — X / Twitter
- [fbclipfast.com](https://fbclipfast.com) — Facebook
- [vidmotionsave.com](https://vidmotionsave.com) — Dailymotion
- [pinmosaic.com](https://pinmosaic.com) — Pinterest, keeps full resolution
- [picvaultsave.com](https://picvaultsave.com) — Instagram photo posts and albums

**Other things I actually use**

- [wakecards.com](https://wakecards.com) — turns a PDF or Word file into flashcards. Used it to cram for a certification exam; worked better than I expected.
- [songfinderlink.com](https://songfinderlink.com) — name that tune, except you paste a link instead of humming
- [tweetarticlesave.com](https://tweetarticlesave.com) — saves an X long-form post as a Word doc, handy when someone writes something worth keeping
- [jobradarly.com](https://jobradarly.com) — job listings that actually come with visa sponsorship

**What doesn't make the list**

Anything that makes you install an extension first. Anything that shows three pop-ups before you reach the download button. Anything that claims to work on "all platforms" — that one is always a lie.

---

If something on this list stops working, open an issue and I'll go retest it.
